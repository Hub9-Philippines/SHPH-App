## Notes

- Interpolated strings keep `{placeholder}` markers — the code interpolates the dynamic value at build time.
- Excluded (not translatable / data / wire): `GCash`, `Maya`, `Card`, `QR Ph`, `COD`, `PHP`, unit format templates (`{n} km`, `{n} jobs`, `{n} min`, `{n}s`, `{h}h {m}min`), provider/place names (`Metro Manila`, `Ramon Dela Cruz`), `'Location loading'` (use the first batch's `Location loading...` key), and `booking_repository.dart` backend `notes` text (stored on the booking, not rendered).
- `'You will confirm a slot shortly'` (B3) is a *different literal* from the approved `'Your slot will be confirmed shortly'` — both need keys.
